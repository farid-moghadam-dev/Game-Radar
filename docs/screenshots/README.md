# Screenshots

Drop PNG screenshots here and reference them from the root `README.md`.

Suggested captures (1080 × 2340, Android 15 emulator or a real device):

| File | What to capture |
|---|---|
| `splash.png` | Splash screen with Lottie animation and app name |
| `home.png` | Home feed — games grid with the carousel header |
| `drawer.png` | Modal navigation drawer open, showing the 5 entity categories |
| `detail.png` | Game detail — top bar with metacritic, rate, platforms, and the about section |
| `entity-list.png` | E.g. Developers list, with one card highlighted |
| `entity-detail.png` | Entity detail — header, description, and games-by-entity grid |
